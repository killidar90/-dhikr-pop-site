Need help with Dhikr Pop?

Dhikr Pop is a simple tactile dhikr counter. Most issues can be resolved with the steps below.

Quick troubleshooting

Restart

Close Dhikr Pop completely, then open it again.

Reset a session

Use the Reset control if you want to restart the current dhikr count.

Update

Install the latest available version from the App Store, or TestFlight while the app is in beta.

Contact support

If you still need help, email us and include a short description of what happened and your device model if relevant.
